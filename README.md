# Fathom

Semester project. One window for synthesising sound, building music from it, and visualising it.

Planned parts:
- synth: oscillators, envelopes, filters
- sequencer: putting sounds into time
- visualiser: a window that draws the audio
- UI: one app that holds all three

Status: empty scaffold. The libraries are not chosen yet, because the course rules decide them (see `docs/`).

## Run

    uv run fathom
